# &Прототип

Псевдоним аннотации [`&Характер("Компанейский")`](https://github.com/autumn-library/autumn) фреймворка autumn.

Задаёт компоненту прототипный способ управления жизненным циклом.

По умолчанию все компоненты являются одиночками: компонент инициализируется один раз, и при
каждом запросе возвращается один и тот же экземпляр. Компонент, помеченный как прототип,
создаётся заново при каждом запросе.

Размещается над конструктором класса или над фабричным методом.

## Параметры

Аннотация не имеет параметров.

## Пример

```bsl
&Прототип
&Компонент
Процедура ПриСозданииОбъекта()
КонецПроцедуры
```

> **Примечание.** Данная аннотация — «душный» псевдоним аннотации `&Характер("Компанейский")`.
> Актуальную документацию см. в [autumn](https://github.com/autumn-library/autumn).
