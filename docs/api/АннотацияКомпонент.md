# &Компонент

Псевдоним аннотации [`&Желудь`](https://github.com/autumn-library/autumn) фреймворка autumn.

Помечает указанный класс как компонент, жизненным циклом которого управляет фреймворк.

Размещается над конструктором класса.

## Параметры

| Параметр | Тип | Описание |
|-|-|-|
| `Значение` | Строка | Имя компонента. По умолчанию будет использовано имя типа объекта, как оно возвращается функцией `ТипЗнч`. |

## Пример

```bsl
&Компонент
Процедура ПриСозданииОбъекта()
КонецПроцедуры
```

> **Примечание.** Данная аннотация — «душный» псевдоним аннотации `&Желудь`. Актуальную
> документацию см. в [autumn](https://github.com/autumn-library/autumn).
