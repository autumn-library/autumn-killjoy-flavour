# &ПослеИнициализацииКомпонента

Псевдоним аннотации [`&ФинальныйШтрих`](https://github.com/autumn-library/autumn) фреймворка autumn.

Процедуры, помеченные данной аннотацией, будут вызваны в конце инициализации компонента, после
отработки конструктора/фабричного метода и всех обработчиков, применяемых на компоненте. Во
время выполнения процедуры доступны все внедряемые зависимости, внедрённые как через
конструктор, так и через поля класса и методы-сеттеры.

Компонент может содержать несколько процедур, помеченных данной аннотацией. Порядок их вызова
не гарантируется.

Процедура должна быть помечена как `Экспорт`.

## Параметры

Аннотация не имеет параметров.

## Пример

```bsl
&ПослеИнициализацииКомпонента
Процедура ПостИнициализация() Экспорт
    Сообщить("Я выполнилась после конструктора объекта");
КонецПроцедуры

&Компонент
Процедура ПриСозданииОбъекта()
КонецПроцедуры
```

> **Примечание.** Данная аннотация — «душный» псевдоним аннотации `&ФинальныйШтрих`. Актуальную
> документацию см. в [autumn](https://github.com/autumn-library/autumn).
