# autumn-killjoy-flavour

`autumn-killjoy-flavour` — это набор «душных» (серьёзных) псевдонимов аннотаций
фреймворка [autumn](https://github.com/autumn-library/autumn). Библиотека для серьёзных
людей, которая убивает много радости при разработке: никаких желудей, дубов и рогаток —
только строгие и понятные бизнесу названия.

Подключите её, если опасаетесь, что код вашего приложения увидит владелец бизнеса и
подумает, что вы упоролись желудями.

## Основные возможности

- Полная совместимость с фреймворком [autumn](https://github.com/autumn-library/autumn):
  каждая «душная» аннотация полностью эквивалентна соответствующей аннотации autumn и
  отличается только названием.
- Серьёзные названия аннотаций для компонентов, конфигураций, фабричных методов,
  обработчиков, внедрения зависимостей и работы с настройками приложения.
- Никаких изменений в поведении — меняется только «вкус» именования.

## Быстрый старт

Установка через пакетный менеджер:

```sh
opm install autumn-killjoy-flavour
```

Подключение в коде:

```bsl
#Использовать autumn
#Использовать autumn-killjoy-flavour

// теперь вам доступны серьезные аннотации (и щи)
```
